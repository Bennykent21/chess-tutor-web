## Stockfish.js

Chess Tutor Web uses the Stockfish.js browser engine package (stockfish 19.0.0), using its lite single-threaded WebAssembly build.

Stockfish.js is distributed under the GNU General Public License, version 3 (GPL-3.0). See the upstream project for the license text and source:

- https://github.com/nmrugg/stockfish.js
- https://www.npmjs.com/package/stockfish

The project uses the browser engine in a Web Worker for local position analysis and computer moves. Engine assets are provided by the npm package at build time.
